## 一、录制前准备（5 分钟搞定）

### 1. 确认三端在运行
```bash
cd /Users/roger/douyinxiangmu
# 若未启动：
npm run dev        # 同时起 后端(4000) / 后台(5173) / 移动端(5174)
# 健康检查应为 healthy：
curl -s http://127.0.0.1:4000/health
```

### 2. 生成新鲜演示竞拍（重要！竞拍有时效，开录前跑一次）
```bash
node scripts/demo-seed.mjs
```
会打印出三场：
- **常规场**（翡翠，5 分钟，用于完整竞价演示）→ 记下编号，如 `#A`
- **短时低封顶场**（字画，2 分钟，封顶 800 元，用于演示「自动延时」和「封顶成交」）→ 记下编号，如 `#B`
- **待开始场**（爱马仕，用于演示主播「手动开拍」）

### 3. 浏览器与账号准备
- **窗口1（移动端·买家A）**：Chrome 打开 `http://localhost:5174` → F12 开「设备工具栏」选 iPhone 12 Pro → 登录 `buyer1 / 123456`
- **窗口2（移动端·买家B）**：Chrome **无痕窗口** 打开 `http://localhost:5174`（同样手机模式）→ 登录 `buyer2 / 123456`
- **窗口3（商家后台）**：另开标签或窗口 `http://localhost:5173` → 登录 `zhubo / 123456`
- 把窗口1、窗口2 左右并排，方便同时展示「领先 / 被超越」对抗。
- ⚠️ 打开后先在直播间点一下页面（解锁浏览器音频，音效才会响）。

### 4. 录制工具
- macOS 最简单：`⌘+Shift+5` → 录制整个屏幕或选定区域。
- 想要更专业（多窗口/麦克风同录）：用 **OBS Studio**。
- 建议同时录麦克风讲解；不便讲解就静音录屏，后期配音或加字幕。

## 三、分镜脚本（操作 + 逐句旁白，约 3 分钟）

> 【操作】= 你要点什么；【旁白】= 照读的话。可后期 1.2~1.5 倍速。

### 镜头 0 · 开场（0:00–0:18）
- 【操作】展示移动端竞拍列表页（直播中 Tab）。
- 【旁白】
  > "大家好，这是我独立开发的全栈项目——**实时竞拍大师**，一套抖音电商直播竞拍系统。
  > 它用 React、TypeScript、Node、WebSocket、MySQL 和 Redis，实现了从商品上架、实时出价到竞拍成交的完整闭环，单直播间支持上千人同时在线。"

### 镜头 1 · 商家 AI 发布竞拍（0:18–0:48）
- 【操作】切到商家后台 → 左侧「发布竞拍」→ 填商品名「和田玉籽料原石」、品类「珠宝」→ 关键词填「羊脂白 油润 收藏」→ 点 **「✨AI 生成」**。
- 【旁白】
  > "先看商家端。我接入了字节火山方舟的**豆包大模型**：商家只要填商品名和品类，点一下 AI 生成，
  > 模型就自动写好卖点文案，还**智能推荐**起拍价、加价幅度、封顶价这些竞拍规则。"
- 【操作】展示自动回填的文案与规则 → 滚动到规则区，指一下「0 元起拍 / 加价幅度 / 封顶价 / 防狙击延时」→ 点「发布竞拍」。
- 【旁白】
  > "规则我都做成可配置的：0 元起拍、按幅度递增、封顶自动成交、临近结束自动延时。一键发布，竞拍立即开始。"

### 镜头 2 · 双人实时竞价 + 氛围（0:48–1:40）
- 【操作】切到左右并排的两个移动端，都进入**常规场 #A** 直播间。指一下顶部在线人数、毫秒倒计时、直播画面。
- 【旁白】
  > "切到用户端直播间。直播画面、当前价、**精确到毫秒的倒计时**、在线人数、实时排行榜，全部 WebSocket 秒级同步。"
- 【操作】买家A 点「⚡一键加价」→ A 屏弹出「🎉领先！」动画 + 音效。
- 【旁白】
  > "买家 A 出价，立刻弹出『领先』的动画和提示音。"
- 【操作】买家B 点「⚡一键加价」→ A 屏弹「⚡被超越！」，B 屏弹「🎉领先！」，两边排行榜实时重排。
- 【旁白】
  > "买家 B 一加价反超，A 这边立刻收到『被超越』的红色警示，排行榜实时重新排序——这种你来我往的紧张感，正是直播竞拍的灵魂。"
- 【操作】两人快速交替多点几次加价，展示价格跳动 + 排行榜动画 + 倒计时。
- 【旁白】
  > "所有人看到的价格、排名、倒计时完全一致，毫秒级对齐，不会错乱。"

### 镜头 3 · 自动延时 + 封顶成交 + 支付（1:40–2:15）
- 【操作】切到**短时低封顶场 #B**（快结束时），在最后 20 秒内出价 → 全场弹「⏱️竞拍延时！」，倒计时延长。
- 【旁白】
  > "看这个细节：临近结束时有人出价，系统自动延时——防止有人卡最后一秒『绝杀』，让竞拍更公平。"
- 【操作】持续加价直到价格到达封顶价 → 自动成交，弹出结果页「🎉恭喜竞拍成功」。
- 【旁白】
  > "价格一旦到达封顶价，自动成交。中标用户弹出结果页。"
- 【操作】点「💳立即支付」→ 显示已支付 → 切到「我的竞拍记录」展示订单。
- 【旁白】
  > "模拟支付后自动生成订单，历史竞拍记录一目了然。"

### 镜头 4 · 商家实时监播 + 取消（2:15–2:35）
- 【操作】切商家后台 → 竞拍管理 → 点某场「监播」→ 展示实时出价流、排行榜、在线人数同步滚动。
- 【旁白】
  > "商家后台还有**实时监播**：出价流、排行榜、在线人数实时滚动；遇到异常竞拍，主播可以一键取消。"

### 镜头 5 · 技术亮点 + 压测数据（2:35–3:00）
- 【操作】切到终端，运行（或展示已截图的结果）：
  ```bash
  npm run loadtest -w @auction/server -- <#A编号> 1000 10 15
  ```
- 【旁白】
  > "最后说技术。为了保证高并发下绝不重复扣款，我用了 **Redis 分布式锁 + MySQL 乐观锁 + 数据库唯一键三重防线**。
  > 压测显示：单直播间 **1000 人同时在线零失败**，一次出价同步给上千端，
  > 我还把在线人数广播从 O(N²) 优化到 O(N)，平均延迟从 219 毫秒降到 **18 毫秒**。
  > 这就是实时竞拍大师，谢谢观看！"
